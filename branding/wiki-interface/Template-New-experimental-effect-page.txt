== Usage ==
'''Subst-only skeleton, not a live template.''' Start a new Experimental
Effect article by creating the page (named after the effect, e.g.
<code>[[Thermal Vent]]</code> — plain page name, matching this wiki's
existing convention) and, as the very first edit, entering:

<pre>{{subst:New experimental effect page}}</pre>

then saving and filling in the placeholders. One page per effect,
covering every compatible module/blueprint combination — don't create
per-module duplicates. See [[Elite Dangerous Field Manual:Engineering
Architecture]] and [[Thermal Vent]] for a populated (but still
placeholder-content) example.
