== Usage ==
Shows a prerequisite chain between Engineers as a linked sequence, each
name reusing [[Template:Related articles]]'s tile styling (a
<code>&lt;span class="edfm-related-links"&gt;</code> wrapping a single
wikilink renders identically to that template's link tiles, since the
CSS targets any <code>a</code> inside a <code>.edfm-related-links</code>
element — no new styling introduced). Up to 6 Engineers, earliest
prerequisite first.

<pre>{{Unlock chain|Engineer A|Engineer B|Engineer C}}</pre>

'''Do not invent unlock relationships.''' Only use this template once a
prerequisite chain has been confirmed against the live game — see
[[Elite Dangerous Field Manual:Editorial Policy]]. Until then, an
Engineer page's unlock-chain section should say the relationship hasn't
been verified yet rather than transclude this template with a guess.
