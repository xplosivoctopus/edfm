== Usage ==
'''Subst-only skeleton, not a live template.''' Start a new Engineering
blueprint article by creating the page (named after the blueprint, e.g.
<code>[[Overcharged]]</code> — plain page name, matching this wiki's
existing convention) and, as the very first edit, entering:

<pre>{{subst:New blueprint page}}</pre>

then saving and filling in the placeholders. One blueprint page covers
the blueprint as a concept across every module it applies to — don't
create per-module duplicates (e.g. no separate "Overcharged (Multi-Cannon)"
page); list every compatible module in the Compatible Modules section of
this single page instead. See [[Elite Dangerous Field Manual:Engineering
Architecture]] and [[Overcharged]] for a populated (but still
placeholder-content) example.

Not every blueprint has grades 1 through 5 — the Grade Comparison table
below includes all five rows as a starting scaffold; delete any grade
rows that don't apply once verified, rather than leaving guessed data in
place of a deleted row.
