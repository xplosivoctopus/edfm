== Usage ==
'''Subst-only skeleton, not a live template.''' Start a new Engineer
article by creating the page (named after the Engineer, e.g.
<code>[[Broo Tarquin]]</code> — plain page name, no namespace/subpage
prefix, matching this wiki's existing convention) and, as the very first
edit, entering:

<pre>{{subst:New engineer page}}</pre>

then saving and filling in the placeholders. Substituting (rather than
transcluding live) means every Engineer page ends up as normal, freely
editable wikitext — no hidden dependency on this template continuing to
exist or match every Engineer's needs exactly the same way. See
[[Elite Dangerous Field Manual:Engineering Architecture]] for the full
Engineering page architecture and [[Broo Tarquin]] for a populated (but
still placeholder-content) example.

Do not invent System/Body/Facility/unlock information when filling this
in — leave a field as "to be added" until it's been checked against the
live game, per [[Elite Dangerous Field Manual:Editorial Policy]].
