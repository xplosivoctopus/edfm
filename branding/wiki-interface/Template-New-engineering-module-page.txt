== Usage ==
'''Subst-only skeleton, not a live template.''' Adds the Engineering
section of a module article — the part covering which blueprints apply
to a given module (weapon, core internal, optional internal, or utility
module).

'''Important:''' [[Ships and Equipment]] already claims
<code>[[:Category:Modules]]</code> for general module articles (base
stats, specifications). A module should have exactly '''one''' page
covering both its general specs and its engineering options — don't
create a second, engineering-only page for a module that already has (or
will have) a general one. If the module's page doesn't exist yet, create
it with this skeleton first and add general-specification sections above
it later; if it already exists, add this skeleton's content to the
bottom of that existing page instead of substituting a new one.

<pre>{{subst:New engineering module page}}</pre>

See [[Elite Dangerous Field Manual:Engineering Architecture]] and
[[Multi-Cannon]] for a populated (but still placeholder-content) example.
