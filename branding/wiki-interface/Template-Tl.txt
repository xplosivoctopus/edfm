== Usage ==
Formats a template name as inline code with a link to the template, for
documentation pages that reference other templates.

<pre>{{tl|Article status}}</pre>

renders as {{tl|Article status}}. Optional extra positional parameters
render as additional literal <code>|param</code> segments, e.g.
<code><nowiki>{{tl|Infobox|name=}}</nowiki></code>.

status}}</nowiki></code>, silently rendering as a red link the whole time
because this template didn't exist yet.
